# Yomi AI

A free personal AI agent that works across your apps and asks before it acts.

Yomi reads your mail, plans your day, drafts replies and runs tasks across 1,500+ apps. Reading happens right away; anything that sends, posts, books or deletes waits for your yes.

**Where to use it:** the web app at [getyomi.in](https://getyomi.in) (installs as an app), Android (in testing), Telegram, Slack, Discord and iMessage (beta), all in one conversation.

**How it's built:** TypeScript on Cloudflare Workers, with Durable Objects (one agent per person), D1, Vectorize, Workers AI and Browser Run for computer use.

### Open source

- [agent-approvals](https://github.com/arka6fx/agent-approvals): ask-before-acting gates for tool-using agents
- [d1-memory](https://github.com/arka6fx/d1-memory): hybrid agent memory on Cloudflare D1 + Vectorize
- [agent-tool-errors](https://github.com/arka6fx/agent-tool-errors): sort tool failures into kinds an agent can act on
